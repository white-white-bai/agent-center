# 实现过程中的待确认事项

> 对应详细设计第 23 章 D01–D12。实现阶段先按可替换的默认方案推进，最终由业务与技术统一确认。

## 一、设计文档已列出的待确认项

| 编号 | 事项 | 当前实现方案 | 影响 |
| --- | --- | --- | --- |
| D01 | 模型来源与部署方式 | 模型网关留有统一接口，测试使用可替换的桩实现；未接入具体厂商 | 模型网关、成本、安全 |
| D02 | 现有身份认证接口 | API 从 `X-Tenant-Id` / `X-User-Id` / `X-Roles` / `X-Permissions` 请求头读取身份，假定由网关注入 | 权限边界、工具透传 |
| D03 | 内容审核接口 | 尚未接入审核服务，输出审核仅保留字段位置 | 输入输出安全、降级策略 |
| D04 | 知识源及 Dify 格式 | 尚未接入 Dify 同步 | 知识迁移 |
| D05 | 向量库选型 | 首期使用数据库关键词检索作为兜底，未接入向量库 | 检索召回与性能 |
| D06 | SSE 部署限制 | 未验证网关/代理超时，未实现事件补发存储 | 长连接可靠性 |
| D07 | 业务写接口幂等能力 | 中台侧已实现幂等表；业务侧是否支持幂等键待确认 | 写操作只执行一次 |
| D08 | 记忆保留期限 | 数据结构已建，TTL 策略未定 | 合规 |
| D09 | Trace 保留期限 | 未实现归档与清理 | 审计与存储成本 |
| D10 | 人工客服工作台接口 | 未实现转人工对接 | 兜底能力 |
| D11 | 评测集与业务基线 | 评测数据结构已建，尚无基线数据 | 迁移收益证明 |
| D12 | 灾备 RPO/RTO | 未定义 | 运维 |

## 二、实现过程中新增的待确认项

| 编号 | 事项 | 当前实现方案 | 建议 |
| --- | --- | --- | --- |
| I01 | 限流与熔断的存储介质 | 进程内滑动窗口与熔断器，多实例部署时计数不共享 | 切换 Redis 实现；确认 Redis 部署与容量 |
| I02 | 会话级分布式锁 | 尚未实现，当前依赖单实例写路径 | 确认 Redis 可用后实现带租约的锁与 fencing token |
| I03 | 数据库迁移方式 | 开发与测试使用 `create_all`，未引入 Alembic 迁移脚本 | 生产前补齐 Alembic 并确认 MySQL 8 版本 |
| I04 | LangGraph 的使用范围 | 运行时先以显式 ReAct 循环实现，接口预留可替换 | 确认是否必须使用 LangGraph，及其版本与运维成本 |
| I05 | 多租户隔离的强制方式 | 服务层每条查询显式带 `tenant_id` | 建议在仓储层统一封装或使用数据库行级策略，防遗漏 |
| I06 | 敏感数据存储 | 工具参数与调用日志目前明文落库 | 确认脱敏规则与加密方案后再上线 |
| I07 | 管理员鉴权 | 管理接口只校验身份，未限制管理员角色 | 确认角色模型后补充 `X-Roles` 校验 |
| I08 | SSE 事件序列与补发 | 尚未实现事件持久化与 `Last-Event-ID` 补发 | 确认是否引入 Redis Stream |
